# 🚀 Getting Started

Follow these instructions to get a copy of the project up and running on your local machine for development and testing purposes.

### Prerequisites

Before you begin, ensure you have the following installed:

- **Node.js** (v12 or newer recommended)
- **Yarn** or **npm**
- **React Native CLI**
- **Android Studio** (for Android development)
- **Xcode** (for iOS development, macOS only)

### 📦 Installation

1. **Clone the repository:**

   ```bash
   git clone https://github.com/cmcodes1/Studify.git
   cd Studify
   ```

2. **Install dependencies:**
   Using Yarn:

   ```bash
   yarn install
   ```

   Or using npm:

   ```bash
   npm install
   ```

3. **Install CocoaPods (iOS only):**
   ```bash
   cd ios
   pod install
   cd ..
   ```

### 🛠️ Running the App

#### 1. Start the Metro Bundler

In a separate terminal, start the development server:

```bash
npm start
```

#### 2. Run on Android

Ensure you have an Android emulator running or a physical device connected.

```bash
npm run android
```

_Note: For Windows users, if you encounter issues, you can use the specialized script:_

```bash
npm run android-windows
```

#### 3. Run on iOS (macOS only)

```bash
npm run ios
```

## 📱 Features

- **Attendance Tracker**: Keep track of your daily attendance for various subjects.
- **Time Table**: Manage and view your weekly class schedule.
- **Subjects Management**: Organize your subjects and related information.
- **Task Manager**: Stay on top of your assignments and deadlines.
- **Concentration Music**: Built-in player for focus-enhancing audio.
- **Profile**: Personalized user settings and overview.
